# meu-segundo-repo
Exercicio ia-1.3 - agente cria repositorio e clona (Agentes de IA, IDP)

## Como este repositorio foi criado

Um agente de codificacao (Claude Code) executou, a pedido do aluno:

1. `gh repo create meu-segundo-repo --public --add-readme` — cria o repositorio publico no GitHub, ja com este README.
2. `gh repo clone tiagocardosos/meu-segundo-repo` — baixa o repositorio para a maquina, com o remoto `origin` configurado.
